# 📌 Project Overview

Telecom Executive Analytics Copilot automatically converts operational telecom KPI data into executive-level business reports using AI.

Instead of manually preparing weekly management reports, the system analyzes telecom KPIs, identifies trends, summarizes network health, and generates decision-ready insights for leadership teams.

- 📉 SLA & Network Health Monitoring
